# Excel planning workbook

[Download NZ_Dairy_Planning_Intelligence.xlsx](NZ_Dairy_Planning_Intelligence.xlsx)

The workbook is the main deliverable of the New Zealand dairy supply and export planning case study. It combines seven review pages, including the Historical Overview of 2015-2025, seasonality, forecast evaluation and exception review.

Use Historical Overview for all eleven years; use the Executive Dashboard year selector (2016-2025) for detailed annual and monthly comparisons. The supporting source tables and calculations are retained within the workbook. For source paths and refresh controls, follow the [Power Query setup](../powerquery/queries/README.md) and [Excel acceptance](../docs/excel_acceptance.md).

The workbook includes embedded milk data. The Stats NZ licence does not extend to those data; redistribution permission for the milk source has not been independently confirmed. See [data sources and reuse](../data/README.md). The original source workbook is not provided separately.

The historical dashboard script is not required to use the workbook.
