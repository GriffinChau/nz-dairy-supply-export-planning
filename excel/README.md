# Excel planning workbook

[Download NZ_Dairy_Planning_Intelligence.xlsx](NZ_Dairy_Planning_Intelligence.xlsx)

The workbook is the main deliverable of the New Zealand dairy supply and export planning case study. It combines historical performance, seasonality, forecast evaluation and exception review.

Use the Executive Dashboard year selector to review the historical results. The supporting source tables and calculations are retained within the workbook. For source paths and refresh controls, follow the [Power Query setup](../powerquery/queries/README.md) and [Excel acceptance](../docs/excel_acceptance.md).

The workbook includes embedded milk data. The Stats NZ licence does not extend to those data; redistribution permission for the milk source has not been independently confirmed. See [data sources and reuse](../data/README.md). The original source workbook is not provided separately.

The historical dashboard script is not required to use the workbook.
