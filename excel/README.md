# Excel planning workbook

The intended final workbook location is `excel/NZ_Dairy_Planning_Intelligence.xlsx`. The workbook contains six visible review pages, with source tables and model calculations retained in hidden supporting sheets.

The full workbook is retained locally until redistribution permission for the milk source and embedded monthly data is confirmed. Hidden worksheets and query caches are still part of the file. Do not publish the full workbook before permission is confirmed; removing a visible tab alone does not remove embedded data.

Before publication, use the final desktop-saved workbook, check the year selector and refresh controls, and remove any personal local paths or sensitive connection metadata from a publication copy while preserving functionality. Use the [Power Query setup](../powerquery/queries/README.md) to configure source paths locally. The historical dashboard script is not required to use the workbook.

See [Excel acceptance](../docs/excel_acceptance.md) for the verified results and outstanding checks.
